# LU Decomposition

A Linear Algebra course project focused on understanding and implementing LU decomposition for matrix factorization.

## Overview

This project explores LU decomposition, a fundamental technique in linear algebra that factorizes a matrix into lower and upper triangular matrices.

The project aims to develop a practical understanding of matrix operations and their computational applications.

## Mathematical Background

LU decomposition expresses a square matrix A as the product of two triangular matrices:

\[
A = LU
\]

where:
- **A**: Original square matrix
- **L**: Lower triangular matrix
- **U**: Upper triangular matrix

When row permutations are required, the factorization can be expressed as:

\[
PA = LU
\]

where P is a permutation matrix.

LU decomposition is widely used in numerical linear algebra, particularly for solving systems of linear equations.
